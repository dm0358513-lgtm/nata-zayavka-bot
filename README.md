# Бот заявок на логистику (для канала natalia_logistic)

Детерминированный бот на Node.js (Telegraf) — без ИИ, без сюрпризов. Задаёт 8 вопросов по порядку (маршрут, ТН ВЭД/санкционность, вид доставки, сборный/контейнер, груз, места и размеры, сроки, опыт растаможки), сохраняет заявку в файл, пересылает Наталье.

## ВАЖНО: нужен НОВЫЙ токен, не тот, что в «Мои боты»

Токен @logistika_natalya_bot уже используется системой «Мои боты» — если использовать его же здесь, включатся два процесса на одном токене одновременно, и Telegram заблокирует бота минимум на 14 часов.

Нужно создать **новый** бот через @BotFather (`/newbot`), с новым username, специально для этого кода. Старый @logistika_natalya_bot можно просто оставить как есть в «Мои боты» или удалить его оттуда, значения не имеет — просто не используем его токен здесь.

## Что нужно, чтобы я задеплоил это сам

1. **Новый токен бота** — создай через @BotFather, пришли (или сразу добавь в /settings → 🔑 как `BOT_TOKEN_NATA`).
2. **RAILWAY_TOKEN** — /settings → Railway → Токен Railway (нужен Railway-аккаунт, тариф Hobby ~$5/мес).
3. **Chat ID Натальи** (куда пересылать готовые заявки) — самый простой способ получить: Наталья пишет любому боту `/start`, затем открывает `https://api.telegram.org/bot<НОВЫЙ_ТОКЕН>/getUpdates` в браузере — там будет её `chat.id`. Могу сделать это сам, если она сначала один раз напишет новому боту.

## Локальный запуск (для проверки перед деплоем)

```bash
npm install
BOT_TOKEN=... ADMIN_CHAT_ID=... npm start
```

## Деплой на Railway

После того как у меня будет `RAILWAY_TOKEN` — создам сервис через Railway API, задам переменные `BOT_TOKEN` и `ADMIN_CHAT_ID`, загружу этот код и запущу. Бот будет работать 24/7 независимо от этого чата.

## Файл заявок

Все заявки также сохраняются в `leads.json` рядом с кодом — простая резервная копия на случай, если пересылка Наталье не сработает.
